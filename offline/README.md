# 一小时一张照片 - 离线版

离线版是纯静态网页,适合自己使用或临时生成图片。

## 使用方式

推荐直接用浏览器打开单文件版:

```text
offline/one-hour-photo-offline.html
```

这个文件已经内嵌 CSS 和 JS,下载单个 HTML 也能打开使用。

开发版文件也可以打开,但需要同目录下同时保留 `styles.css`、`storage.js`、`app.js`:

```text
offline/index.html
```

数据会保存在当前浏览器的 `localStorage` 中。换电脑、换浏览器或清理浏览器数据后,这些内容不会自动同步。

## 特点

- 不需要服务器
- 不需要 Supabase
- 不需要 Netlify
- 支持图片压缩、裁剪、缩放
- 支持文字拖拽和样式调整
- 支持导出单张 PNG

## 限制

- 不能多人协作
- 分享链接不会携带完整图片数据
- 本地浏览器空间有限,不适合长期保存大量照片
